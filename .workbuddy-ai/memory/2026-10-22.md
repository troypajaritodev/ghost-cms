### Environment gotchas
- `next build` fails with a safe-delete ETIMEDOUT / EPERM on `.next` — always run builds as `CODEBUDDY_SAFE_DELETE_ENABLED=0 npx next build`, and `rm -rf .next` with the same env var.
- Cache Components is on: `new Date()` during prerender throws. Avoid runtime dates in server components.
- `npx eslint .` enforces `react-hooks/set-state-in-effect` — don't call setState directly in an effect body.
- Headless Edge screenshots silently produce no file in this sandbox; no visual screenshot verification available.
